【最大ダメージ計算（前回版と同じ）】
A = 敵の攻撃力、B = 現在守備力、X = A - floor(B/2)、D = floor(X/2)
X <= 1                    -> 最大1
D <= floor(A/16)          -> 最大floor(A/16)
それ以外                  -> 最大D + floor(D/16) + 1
バイキルトあり             -> 算出した値を2倍
これは公開攻略資料に基づく実装で、SFC版ROM内部の処理との完全一致は未検証です。
