DQ6 守備力・ダメージ計算 Webアプリ v8
========================================

今回の変更点（v7 → v8）
1. 右上「データリセット」で最大HPを保持する。
   リセット対象：全員の守備力上昇量、敵の攻撃力（410に戻す）、バイキルト（なしに戻す）
   保持対象：初期守備力、最大HP、キャラクターの表示・非表示
2. バイキルト「なし」「あり×2」の2つのボタンを、
   全体操作の「ルカナン」「スクルト」と同じ横幅・高さに変更。
   iPad横向き、縦幅の短い画面、スマホ表示時もサイズを連動。
   「あり」選択時の赤色は維持。
3. HTMLのリセット説明文とサービスワーカーのキャッシュをv8に更新。

GitHub Pagesに公開する方法
- リポジトリの index.html / app.js / style.css / sw.js を同名で置換してCommit。
- 初回導入・欠損時はmanifest.jsonとicons/も追加。
- GitHub ActionsでPagesのデプロイが成功した後、Safariで再読み込み。

注意：ダメージ計算はv7から変更していません。ROM内部との完全一致は未検証です。
