DQ6 守備力・ダメージ計算 Webアプリ v7
========================================

変更点（v6 → v7）
1) 全体操作から「上昇量リセット」を削除。全体ルカナン・スクルトを2列の幅広ボタンに変更。
2) バイキルト「あり」を選択したとき赤色（非選択時は中立色）で表示。
3) 事前設定の「初期守備力」の下に、4人分の「最大HP」入力欄を追加。
4) 各キャラの最大ダメージが、そのキャラの最大HP以上なら、ダメージ表示を赤色に変更。
   - 最大HP未入力は判定せず、緑のまま
   - 最大HPと最大ダメージが一致する場合も赤色
5) 右上「データリセット」では最大HPを空欄に戻す。
   これまで通り、初期守備力とキャラの表示・非表示は保持する。
6) データ保存は従来のlocalStorageキーを維持。v6以前のデータも読み込む。

公開方法
- GitHubのリポジトリ直下にある index.html, app.js, style.css, sw.js を同名で置換しCommit。
- 初回導入またはファイル不足時はicons/、manifest.jsonもアップロード。
- GitHub Actionsのpages build and deploymentが成功した後に、公開ページを再読み込み。
- キャッシュが古い場合はSafariを再読み込み。PWAの再起動も試してください。

計算処理について
- SFC版DQ6の通常攻撃ダメージ計算式はv6から変更していません。
- 通常攻撃最大値が実機ROMの端数処理まで一致するかは未検証です。
- HP欄は判定の閾値のみに使用し、ダメージ計算そのものには影響しません。
