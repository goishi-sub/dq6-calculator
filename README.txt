DQ6 守備力・ダメージ計算 — iPadホーム画面用 Webアプリ (PWA)

【使い方】
1. GitHub に無料アカウントを作る。
2. 「dq6-calculator」などの公開リポジトリを新規作成する。
3. このフォルダ内のファイルと icons フォルダをそのままリポジトリにアップロードする。
4. リポジトリの Settings → Pages → Deploy from a branch → main / (root) → Save。
5. 発行されたURL (https://ユーザー名.github.io/dq6-calculator/) を iPad の Safari で開く。
6. Safari の共有 → ホーム画面に追加 → ウェブアプリとして開く → 追加。

【注意】
・アプリの初期守備力は4人とも空欄です。各キャラの黄色欄へ入力してください。
・数値は端末内に保存します。iPadのWebサイトデータ削除等で消える場合があります。
・GitHub Pagesで公開するとアプリのプログラムは誰でも閲覧できます。
・オフライン使用はオンラインで一度起動してファイルが保存された後に可能です。
・スプレッドシートとデータは自動同期しません。

【計算】
現在守備力=初期守備力+上昇量
上昇量の上限+200、下限=−初期守備力
ルカナン=−floor(初期守備力/4)、スカラ=+floor(初期守備力/2)
スクルト=+floor(初期守備力/4)
ダメージ=ROUNDDOWN((攻撃力/2−現在守備力/4)×(バイキルト時2、通常時1),0)

※オリジナルのDQ6計算シートをもとにした非公式の個人用計算ツールです。
