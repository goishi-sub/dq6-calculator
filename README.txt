【通常攻撃 最大ダメージ】
A=攻撃力、B=現在守備力、X=A-floor(B/2)、D=floor(X/2)
条件1: X<=1                -> 最大1
条件2: D<=floor(A/16)      -> 最大floor(A/16)
条件3: それ以外            -> 最大D+floor(D/16)+1
バイキルトあり             -> 最終ダメージを2倍
小数点以下は計算途中で切り捨て。
会心・痛恨・特殊攻撃・防御・耐性による補正は含めていません。
解析資料に明示されないROM内部の細かい切捨て順序までは実機未検証です。
