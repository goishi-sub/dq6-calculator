DQ6 守備力・ダメージ計算 v6（ダメージ移動＋立体ボタン）

【変更点】
1. キャラカード内の「通常攻撃・最大ダメージ」を削除して、個別操作と全体操作の間へ移動。
   横並びのダメージ欄は表示中のキャラと同じ順・列幅に自動調整します。
2. 個別操作ボタンをiPadの十分な画面高さでは90px→180pxへ拡大。
   画面の縦幅が短いiPadでは、バイキルトが画面内に収まるよう高さを自動縮小します。
3. ルカナン／スカラ／リセット、全体操作、バイキルト、表示切替、右上リセットに
   立体的な影・縁取り・押下時に沈み込む演出を追加しました。
4. 上昇量・最大ダメージなどの数値欄は平面的なデザインのままです。
5. 攻撃力、初期守備力、保存、絞り込み、データリセット時の絞り込み維持はv5から変更なし。
6. 計算式はv5のまま（ROM内部の細部まで一致するかは未検証）。

【GitHub Pagesへの反映】
既存のリポジトリ直下の以下4ファイルを上書きしてコミットしてください。
- index.html
- app.js
- style.css
- sw.js
manifest.json と icons フォルダは変更なし。

【更新時の注意】
CSS/JSの参照クエリとService Workerキャッシュをv6に更新しています。
古い画面が残る場合はSafariのリロード、ホーム画面のアプリ再起動を試してください。
localStorageのキーは従来どおりで、保存値は引き継がれます。
