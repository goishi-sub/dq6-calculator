DQ6 守備力・ダメージ計算 v5（戦闘中の操作ボタン拡大・絞り込み保持）

【v4からの変更点】
1. PARTY STATUS／キャラクター別／上昇量と最大ダメージを確認・操作の見出しを削除。
2. 各キャラのカード上部の「上昇量」ラベルを削除。「初期値からの変化」の数値欄は維持。
3. 個別操作・全体操作・バイキルトの3つの操作行のボタンを縦方向に拡大。
4. 右上の「全設定リセット」を「データリセット」に名称変更。
5. データリセット時にキャラクターの表示／非表示の絞り込みを変更しない。
   初期守備力も以前と同様に保持。上昇量は0・敵攻撃力は410・バイキルトはなしに戻す。
6. キャラの表示人数によるカード幅自動調整、非表示中のデータ保持、保存機能を継続。
7. ダメージ計算とバフ・デバフ処理はv4から変更なし。
8. CSS/JSの参照番号とオフラインキャッシュをv5に更新し、旧表示の残存を防止。

【GitHub Pagesへの反映】
既存のリポジトリ直下で以下4ファイルを同名で上書きしてコミットしてください。
- index.html
- app.js
- style.css
- sw.js

その他のmanifest.jsonとicons/は既存から変更していません。
ZIP全体をアップロードする場合は展開してから中のファイルをアップロードしてください。
コミット後にGitHub Actionsのpages build and deploymentを確認し、Safariで再読み込みしてください。

【保存データ】
ブラウザのlocalStorageキーは変更していないため、v4で設定した初期守備力や絞り込みを引き継ぎます。
「データリセット」でも絞り込みを保持します。

【計算の注意】
通常攻撃の最大ダメージ計算は以前のv4と同じ近似実装を維持。
SFC版ROM内部の端数処理との完全一致は検証していません。
