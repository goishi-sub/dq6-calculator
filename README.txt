DQ6 守備力・ダメージ計算 Webアプリ v9
========================================

今回の変更点（v8 → v9）
1. キャラカードの「初期値からの変化」を「守備力上昇量」に変更。
2. 守備力上昇量の色分けを以下に変更。
   - 0未満: 赤色（従来どおり）
   - 0以上200未満: 通常のグレー背景・標準文字色
   - 200: 緑色（従来どおり）
   （最大値は +200。文字表示は +200 のままです。）
3. スクルトの背景・文字・枠・立体的な影を、個別のスカラと同じ青色に変更。
4. キャッシュのバージョンを v9 に更新。

v8のその他の動作を維持
- 最大ダメージの計算・最大HP以上のとき赤色警告
- 最大HP・初期守備力・キャラ表示/非表示の保存
- 右上データリセット後も最大HPなどを保持
- バイキルト「あり」の赤色選択ボタン
- 4人のカード幅自動調整

GitHub Pages での更新
index.html / app.js / style.css / sw.js を同名ファイルに置換してコミット。
既存の manifest.json と icons/ は変更不要です。
GitHub Actions の Pages デプロイを確認し、Safari を再読み込みしてください。

注意: 既存のダメージ計算方式は変更していません。ROM内部との完全一致は未検証です。
